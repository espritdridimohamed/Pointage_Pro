The service was registered with wrong Java path (jdk instead of jre).
Remove and re-register with correct path.

Copy and paste ALL these commands:

& nssm stop PointagePro
& nssm remove PointagePro confirm
& nssm install PointagePro "C:\Program Files\Eclipse Adoptium\jre-17.0.13.11-hotspot\bin\java.exe" "-jar" "C:\PointagePro\backend\pointagepro.jar"
& nssm set PointagePro AppDirectory "C:\PointagePro"
& nssm set PointagePro AppStdout "C:\PointagePro\logs\stdout.log"
& nssm set PointagePro AppStderr "C:\PointagePro\logs\stderr.log"
& nssm set PointagePro Start SERVICE_AUTO_START
& nssm start PointagePro

Verify it's running:
& nssm status PointagePro

============================================
  TROUBLESHOOTING
============================================

Service won't start:
  Check Java path:
  Get-Command java | Select-Object -ExpandProperty Source
  Then re-register service with correct path (see Step 7).

Apache port 80 in use:
  Already running from xampp_start.exe - no action needed.

MySQL not working:
  & "C:\xampp\xampp_start.exe"

Can't access from other PC:
  Check firewall rules (Step 8).
  Check company PC's IP with: ipconfig
